# LUNC Battlefield v11.2 — extra smoothness (draft)

Branch `feat/v11.2-smooth`, stacked on `feat/v11.1-perf` (PR #7). Visual/perf only. No market, price,
feed, label, frontline, army-count or LIVE/CALCULATED code was touched.

## Changes

1. **Pre-baked soldier poses** (`assets/models/v11/soldier-poses.bin`, 361 KB). All 28 soldier poses
   (idle/walk/run/shoot) are baked offline by `tools/v11.2/bake-poses.js`, which runs the exact v11.1
   runtime bake in headless Chrome and serialises it (int16 bbox-quantised positions, < 0.1 mm error on a
   1.32 m soldier; int8 normals; per-vertex mesh id). At load the game fetches the pack and skips both the
   426 KB `soldier.glb` download and the skinning bake. Faction/token colours are re-derived at load with
   the same rules as before. Fallback: missing/corrupt pack → v11.1 runtime bake (`?v11poses=runtime` forces it).
   Regenerate the pack whenever `soldier.glb`, clip list or soldier colours change.
2. **Shadow cache** (`battle-engine.js`). The sun is fixed and most casters are static, so the shadow map
   is no longer redrawn every frame (r128 also redrew it on every scene render call). It refreshes for
   moving units on a tier cadence — ULTRA every frame, HIGH every 2nd, MEDIUM/LOW every 3rd, every 30th
   while paused — and immediately on quality/size/sun change or `LUNCBattle.shadowCache.invalidate()`.
   Tier shadow types and map sizes are unchanged. `?shadowcache=0` restores per-frame shadows.
   Note: three r128 has a single shadow map per light, so this is a cached/throttled map, not a separate
   static+dynamic split (that needs a custom depth-composite pass; candidate for later).
3. **Batched particles** (`effects.js`). Sparks, smoke, debris, embers, flashes and fire puffs are now
   lightweight proxies packed each frame into one `InstancedMesh` per type (per-instance colour+opacity via
   a small shader patch, same textures/blending; smoke is still sorted back-to-front). A burst costs ≤ 6
   draw calls instead of one per particle. Spawn/caps/lifetimes unchanged.
4. **Distant soldier stand-ins** (`v11-units.js`). Each pose gets a low-poly version built at load by
   vertex clustering (4.5 cm cells, never across materials): 2,624 → 1,143 triangles (−56%), ~15 ms total.
   Soldiers beyond the tier distance (LOW 30, MEDIUM 38, HIGH 48, ULTRA 60 m, ±2 m hysteresis) use it;
   the LOD uses every 2nd pose so it adds few batches. `?v11lod=0` disables.
5. **Low-risk extras.** Hidden procedural meshes under V11 units skip local matrix composition
   (restored if V11 is turned off); per-frame `forEach` closures in `animations.js` replaced by loops;
   the loader also compiles the render-target / no-tone-mapping shader variants and seeds one hidden
   scorch, shock ring, fire puff and each projectile type, which removes the last mid-play program compile
   (v11.1 still compiled 1 program on the first big blast).
6. BUILD `v11.2`, cache-bust `?v=20261011v112`.

# V7.1 Terra Intelligence Backend

Cloudflare Worker that aggregates Terra Classic LCD + public market APIs into a truth-labeled JSON envelope for the Battlefield frontend.

## Architecture

```
GitHub Pages (static)  --?api=-->  Cloudflare Worker
                                    ├─ providers/terra.js      LCD failover
                                    ├─ providers/binance.js    vision → api
                                    ├─ providers/defillama.js  price fallback
                                    ├─ providers/coingecko.js  price fallback
                                    ├─ providers/entities.js   conservative labels
                                    ├─ lib/cache.js            in-memory TTL Map
                                    └─ routes/*                envelope responses
```

- **Format:** ES module `export default { fetch }`
- **CORS:** `*` for GET/OPTIONS (Pages)
- **Timeouts:** ~8–12s per upstream
- **Dual mount:** `/api/snapshot` **and** `/snapshot` (same for burns, whales, governance, validators)

## Envelope

```json
{
  "status": "ok|partial|unavailable",
  "truth": "LIVE|CALCULATED|ESTIMATED|SIMULATED|UNAVAILABLE|PARTIAL",
  "source": "binance|terra-lcd|defillama|coingecko|aggregate|…",
  "sourceLabel": "human label",
  "timestamp": "ISO-8601",
  "stale": false,
  "confidence": 0.0,
  "data": {},
  "error": "optional reason"
}
```

## Failover

| Feed | Order |
| --- | --- |
| Terra LCD | `TERRA_LCD_URLS` or publicnode → hexxagon |
| Binance REST | `data-api.binance.vision` → `api.binance.com` |
| Spot price | Binance bookTicker → DefiLlama → CoinGecko |

## Cache TTLs

| Key | TTL |
| --- | --- |
| prices / market | 8s |
| orderbook | 5s |
| burns / whales | 30s |
| governance | 60s |
| validators | 120s |
| supply / network | 60s |
| snapshot | 8s |

## Feed status matrix (design)

| Route | Expected truth | Notes |
| --- | --- | --- |
| `/health` | LIVE | Upstream probe summary |
| `/market/LUNC\|USTC` | LIVE or PARTIAL | Binance mid; fallbacks PARTIAL |
| `/orderbook/LUNC\|USTC` | LIVE | Depth 100–500 + zone metadata |
| `/liquidations` | **UNAVAILABLE** | forceOrder needs WS / DO — never fake |
| `/burns` | PARTIAL / UNAVAILABLE | Best-effort LCD burn scan; never count sends |
| `/whales` | PARTIAL / UNAVAILABLE | MsgSend ≥50M LUNC or ≥$25k USTC; no buy/sell guess |
| `/governance` | LIVE / PARTIAL | gov v1beta1 (+ v1 fallback) |
| `/validators` | LIVE | Bonded set + VP% |
| `/supply` | LIVE / PARTIAL | uluna + staking pool + community pool |
| `/network` | LIVE / PARTIAL | height, chain-id, active vals; tax may be UNAVAILABLE |
| `/snapshot` | PARTIAL aggregate | Each nested feed keeps own truth |

## Conservatism

Burns and whales prefer **PARTIAL/UNAVAILABLE** over incorrect **LIVE**. Ordinary bank transfers are never counted as burns. Whale classification defaults to `unknown whale movement` unless the address is in the conservative exchange list in `entities.js`.

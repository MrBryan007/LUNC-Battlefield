# LUNC Battlefield v11.1 — freeze / lag fixes

Branch `feat/v11.1-perf`, based on `feat/v11-realistic-units` (66dd6f1, draft PR #6). **Draft only. Not merged, not deployed.**
Scope: v11.1 section of DEEP-DIVE-V11 (fixes 1-7). Nothing visual was redesigned. No market, price, feed, frontline, or LIVE/CALCULATED logic or labels changed.

## Changes
1. **Fixed flash-light pool (biggest freeze).** `effects.js` now creates its 3 flash PointLights (1 on phones) at startup and never adds/removes them; "off" = intensity 0. `commander.js` creates the strike `blastLight` at init instead of on the first strike. The scene light count no longer changes during play, so explosions/strikes no longer force every lit material to recompile.
2. **No more timed army teardown.** The random "every 7-40 s rebuild everything" in `updateBattleLogic` is replaced by `syncArmyCounts()`: every 7 s it recomputes the same market-driven counts and, only if they changed, adds/removes the difference (`units.updateArmy`). Survivors are re-homed onto the same deterministic formation slots. Full rebuild still happens at startup, on token switch and forced-GLTF swap. Army-size math is hoisted verbatim into `armyCounts()`.
3. **Loading screen + shader warm-up** (`js/loader.js`, overlay in `index.html`). Waits for the engine and the V11 bake (progress bar), spawns one explosion/strike/tracer/muzzle flash/Commander blast behind the overlay, temporarily shows every hidden object (V11 batches, reticle, pools) and calls `renderer.compile`, then lets 2 real frames (bloom/MSAA) render before fading out. `?loader=0` skips it.
4. **V11 animation bake moved behind the loader and chunked per pose** (28 short tasks instead of 4 long ones); per-vertex allocations removed from the skinning bake. Shipping pre-baked pose files (fully offline bake) is deferred to v11.2.
5. **Per-frame allocation cleanup:** escort quaternion is a reused scratch, `forEach` closures in the V11 per-frame path replaced with loops.
6. **Binance book throttle:** depth messages are still merged into the local book on every message (book identical). Only the stateless `applyLiveBook()` and the DOM status refresh are coalesced to ≤ 8 Hz, using the mid captured from the newest message. bookTicker price updates are not throttled at all.
7. **Frame-aligned timers:** `updateBattleLogic` (760 ms) and the UTC clock run from the rAF loop with an accumulator; a watchdog interval keeps logic running if rAF is suspended (background tab).
- BUILD → v11.1, all `?v=` cache-busters → `20261010v111`. v9.4.17 phone-freeze fix untouched (price-territory.js not modified).
- Debug hooks: `LUNCBattle.engine.getArmyStats()`, `getBookStats()`, `LUNCBattle.loader.getState()`, `LUNCBattle.perfStats` (long tasks).

- `node --check` on every JS file: pass.
- **Data unchanged:** `tools/v11.1/data-compare.js` loads v11.0 and v11.1 side by side with a seeded RNG, offline fetch and a mock Binance socket, feeds the identical 240-message depth/bookTicker stream in 6 bursts, and snapshots market state, walls, imbalance, zones/truth labels, price and the HUD text after each burst: **6/6 checkpoints byte-identical**. `tools/v11.1/counts-test.js`: old vs new army-count formula, 4,565 cases across 5 screen widths, **0 mismatches**.
- **Freeze fix:** `tools/v11.1/strikes.js` fires Artillery, Airstrike, Moon Shot and 8 explosions after load. v11.0: lights 6→9, shader programs 32→72 (40 recompiles mid-play). v11.1: lights 10→10, programs 55→56.
- `tools/v11.1/smoke.js`: desktop + iPhone viewport, loader completes, no page errors, LOW/MEDIUM/HIGH/ULTRA/AUTO all switch, all 3 Commander strikes fire, diffed army path active (no full rebuilds after start). Only console errors are CoinGecko CORS from localhost (pre-existing, not on GitHub Pages).
- SwiftShader frame times/long tasks are not meaningful for the M1; real FPS must be checked on the Mac and iPhone.

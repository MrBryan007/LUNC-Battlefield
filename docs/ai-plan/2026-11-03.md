## Cycle 2 → v12.0.53 "Online link-up, part 2: the host's market drives both battles" (v12.2 Online)
Roadmap: "The host fetches market data and broadcasts it so both players see the same battle."
1. Host sends its token and spot price (with its source and LIVE / SIMULATED truth) every 2 s and on each change.
2. Guest: "Follow host's market" toggle (on by default once linked). While following, the engine ignores its own
   feeds and its own simulation drift, and takes the host's price through the normal price path, so the front, walls
   and momentum follow the host. If the host's token differs, the guest switches token.
3. Data-truth labels stay honest: a host LIVE price shows as "LIVE · BINANCE VIA HOST" (source keeps its name plus
   "via host"); a host SIMULATED price stays SIMULATED, never promoted to LIVE.
4. Falls back to the guest's own feeds if the host goes quiet for 12 s, the link drops, or the toggle is turned off.
5. Validation: known token only, price finite and within 0.05x–20x of the token's base, source label from a fixed list.
6. Panel shows "Market: following host · LIVE · Binance" and the front comparison should now match.
Kill switch `?hostmarket=0` (and `?online=0` turns off all of it). Engine gets a small remote-spot hook only.

Cycle 2 result: deployed v12.0.53 (main 30b4366), live 06:41 PT. Guest follows the host's LIVE price with the same
price window (fronts matched), honest "VIA HOST" labels, fallback on quiet / untick, `?hostmarket=0`.
